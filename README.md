# ArchDotfiles
My Arch + Noctalia + Hyprland dotfiles

Files belong in ~/.config/hypr/ ~/.config/noctalia/ ~/.local/state/noctalia/ ~/.config/kitty/ ~/Wallpapers/ ~/.config/vesktop/themes as labeled, please back up your own dotfiles before importing mine. Luciole file picker, Kitty terminal with Fish shell, Vencord, and xdg-desktop-portal-hyprland are assumed. These are dotfiles, not an installer. If a file causes something to break, don't include it.
